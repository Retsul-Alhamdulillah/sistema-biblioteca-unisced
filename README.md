# Sistema de Gestão de Biblioteca Municipal (Java Console)

Este projeto consiste num sistema baseado em consola desenvolvido para a gestão de inventário de livros e controlo de empréstimos da Biblioteca Municipal, como parte da avaliação da cadeira de **Introdução a Algoritmos e Programação** na **UnISCED**.

## 🚀 Funcionalidades
- **Registo de Livros e Utilizadores:** Adição de obras e leitores com verificação de ID único.
- **Consulta e Pesquisa:** Listagem do catálogo completo e busca por título ou autor.
- **Gestão de Empréstimos e Devoluções:** Controlo de estoque e histórico de movimentações.
- **Estatísticas:** Exibição do livro mais requisitado e totais operacionais do acervo.

## 🛠️ Tecnologias e Estruturas de Dados
- **Linguagem:** Java (JDK 8 ou superior)
- **Estruturas de Dados:** Vetores (Arrays unidimensionais) e Matrizes multidimensionais para simulação de base de dados em memória.

## 📋 Pré-requisitos
- Java Development Kit (JDK) instalado (versão 8+).
- Terminal/Prompt de Comando ou uma IDE Java (VS Code, Eclipse, IntelliJ).
